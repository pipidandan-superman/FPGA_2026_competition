# 侧视布置检查清单（L4 板载相机标定前置）

> 方法一句话：目标物都坐在桌面工作平面上 → 像素 (u,v)→臂基 (X,Y mm) 是 3×3 单应 H，
> **任意相机角度都成立**；侧边只改精度分布，不改方法。Z=固定下爪高度。
> 侧视代价公式：参考点离面高度 h → 横向漂移 ≈ **h/tanθ**（θ=俯角）。θ=20° 时 5mm 漂 ~14mm；θ=60° 时 ~3mm。

## A. 机位与布置门槛（装完逐项打勾）

| # | 项 | 门槛 | 检查法 |
|---|---|---|---|
| A1 | 相机俯角 θ | **≥45°，目标 50°+**（镜头距桌面 ≥60-80cm，水平距操作区近缘 ≤60cm） | 量测；或 park 快照里用桌面参照线估算 |
| A2 | 操作区位置 | **画面近半场**；深度方向 ≤250-300mm；避开臂基坐标系 y≈0 奇异线 | 在布置图上圈出瓶子活动范围 |
| A3 | FOV 与遮挡 | 臂 park 态 + 整个操作区同框；**park 态下操作区无任何臂体遮挡** | 判据见 B1 |
| A4 | 主光源 | 从相机侧来，防逆光（目标物无剪影） | 实况帧目检 |
| A5 | 操作区底色 | 浅色垫（白纸/白卡）——定义标定平面兼提升 YOLO 对比度 | 目检 |
| A6 | 目标物 | 演示用 COCO 类（瓶/杯）；深灰方块只作标定道具 | — |
| A7 | 固连与定位 | 板夹紧防晃；线缆应力释放；**三脚脚位在桌面贴胶带定位刻线** | 轻晃板子无可见位移 |
| A8 | 摆位 | 臂基座与相机分居两侧，臂从侧后方伸入操作区 | 布置图 |

## B. 验收快照（装完当天拍三张入证据）

1. **PARK_VIEW**：臂 park 态实况帧 → 操作区全部可见、无臂体遮挡 ✔
2. **OVERVIEW**：全景（三脚架+板+臂+操作区+脚位贴线）入镜 ✔
3. **REFOBJ**：自检参照物（放操作区近缘、臂可触及、点得到）✔

## C. 标定 run 验收门（calib_plane_h.py 自动判）

| 门 | 判据 |
|---|---|
| CALIB_COLLECT_PASS | ≥9 点（默认 12）；每点**指尖贴面**+垂直接触约定 \|alpha+90°\|≤10° |
| CALIB_H_PASS | RANSAC 单应重投影残差中位 <2px |
| CALIB_VALIDATION_PASS | 随机 5 点（**必须含 ≥1 远场点**，--far 标注）逐点误差 <10mm |
| 远场超差处理 | **收缩操作区，不放水**；改布置=重标 |

采图通道（板窗口）：板上 v1.4 相机链路存 PNG → scp 到 PC → `--frame-dir` 逐点投 `point_XX.png`。

## D. 运行期纪律

- 每次上电 **30s 自检仪式**：`selfcheck` 模式点 REFOBJ 参照物 → **SELFCHK_PASS 才开演**；
- 脚位刻线移位 / 线缆重插 / 板子被碰 / 臂基被挪 → 全部触发重标（清单 A7 是检测手段）；
- 运行时检测框取点=**框底边中点**（触地点在标定平面上），N 帧中位去抖；
- 证据落盘 `4_metrics/logs/<date>_model_arm_calib_runNN/`；H 资产=`calib/homography.json`（进 git，版本化）。

## E. 重标触发清单（何时必须回到 C）

臂/板相对挪动 · 相机焦距/镜头被动 · 支架拆装搬运（脚位贴线之外）· 换桌子 · SELFCHK 连续 FAIL。
